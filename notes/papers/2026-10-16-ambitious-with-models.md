# How to be more ambitious：人类与模型协作的野心教程

> 原文：[felixrieseberg.com](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/)（2026-10-13 发布）

> 作者 Felix Rieseberg 是 Anthropic 的 EM，带过 Claude.ai、Cowork、Claude Code Desktop 的工程团队，也是 Electron 的共同维护者。这篇不是论文，是他观察「为什么有人用 Claude 用得飞起、有人只会问法国首都」之后写的实操教程。核心框架：野心分四种——Speed / Altitude / Depth / Range，前一种人人都在用（不值得讲），后三种才是拉开差距的地方。结尾用心理学的 self-efficacy 解释了为什么大多数人需要这份教程：不是模型不行，是人不敢想。

## 背景与动机

AI 圈天天喊「we're not ambitious enough」，但没人告诉你怎么做到。作者每天的日常就是看别人用 Claude 做出他自己都没想到的东西——帮忙发现新行星、做出第一条真正好听的 AI 音乐视频——同时大量用户还停留在「帮我改改邮件语气」。

Terence Tao 的观察是底层原因：模型能力不是均匀涨的，是「某些方向强得吓人、某些方向还不够用」。会开的人贴着强方向飞，不会开的人拿着 wings 不知道干嘛。这篇就是把「会开的人」的姿势拆成可复制的技巧。

## 方法：野心的四种类型

| 类型 | 一句话 | 判断信号 |
|---|---|---|
| Speed | 同样的活干快点 | 人人都在用，无技巧可言 |
| Altitude | 往上抽象一层，盯结果不盯任务 | 这事开完会还要讨论 → 适合拔高 |
| Depth | 往下钻一层，按领域顶尖专家的标准干活 | 任务要「执行得特别好」 |
| Range | 跨领域借兵，把不相干领域的方法拉进来 | 任务卡在单一视角时 |

### Altitude：goal beyond the goal

关键自问：**这事做完之后你想发生什么？** 作者自己的转变：去年初还在让 Claude 修单个 crash，后来直接说「让我们的 app 保持无 crash」——从「修 bug 的」变成「维护无 crash 状态的」。

用季度经营评审（QBR）做例子，三级递进：

1. **喂全量数据**：别只让模型填模板数字，把能拿到的业务数据全给它——「告诉我这季度什么变了、为什么、该怎么办」。
2. **逼出决策**：好会议要有结论——「从你学到的东西里挑出三个最紧迫的决策，每个给出正反方向的初步论证」。
3. **质疑流程本身**：QBR 这个形式本身就是前 AI 时代人工翻数据的遗产——「评审的目的是让管理层早发现问题、把人和钱挪对地方。设计一个比季度 deck 更好的方式，用我们自己的历史数据证明它能更早catch到问题，并行跑一个季度」。

拔高的代价是改造工作流：想让 Claude 负责「无 crash」，先得让它能拉 crash 报告、知道 app 版本对应哪个 git commit、给它三平台电脑去独立复现验证。**durable workflow 的前提是把环境喂够**——这与 agent 工程的共识完全一致。

### Depth：按顶尖专家的标准干活

五个技巧，全部针对「模型嘴上专业、手上业余」的问题：

- **坚持用行业顶尖的仪器**：模型被要求「像专业人士一样」时常换个词汇不换方法。Claude 想用 markdown 表格交差时，坚持要数据库和统计模型。你不需要知道专家用什么，模型知道。
- **定不讲理的目标，然后告诉模型这很合理**：网站从 10s 提到 5s？直接要 200ms。模型说不可能？重申可以解决，继续干。
- **对着自己的认知开炮**：商业里很多「共识」只是现实的粗略近似。给模型原始数据，让它对抗性检验假设——「我们相信 churn 是 onboarding 问题，从原始数据里复现这个结论试试」。
- **制造新知识**：让模型在数据里找盲区——「用日志重建一个能复现过去一年的客户模拟器，然后找一个我们还不知道的最早 churn 信号，并在没见过的数据上验证它有预测力」。
- **用外部裁判**：不要让模型给自己打分。2026 年 10 月的现状下，坚持外部验证——最好是模型能自己跑、立刻拿反馈的工具。

附赠一个作者常用的「深挖 prompt」：

> 我要这个任务更深的版本，不是更大的版本。重写前先回答：(1) 这个领域的顶尖专家会做哪些我没要求的事；(2) 他们会从什么最原始的材料入手（而不是已经被消化过的）；(3) 他们会用什么具体方法和工具；(4) 除了你我之外，什么能证明结果是对的。然后把我的 prompt 改写成要求恰好这些的版本。

### Range：跨领域组团

抢银行电影前 30 分钟都在组队——多 agent 时代，把不同领域的方法拉进来从未如此便宜。作者直到看见同事用 Blender 渲染室内设计才想到用 Claude 做 3D 环境——而他以前是做游戏的。

- **名词换动词**（出自《The Art of Innovation》）：季度评审不是「一个 deck」，是「让忙碌的人在 30 分钟内相信一个关于因果的故事、并在不确定下做出决策」。动词版本让跨领域能力自己浮出来。
- **组队**：deck 做不好地球就炸了，人类该组什么队？分析师 + 记者 + 编辑保产出，动效师 + 音频师保呈现，再加个红队——空头分析师和法务会计来对抗性挑刺。

一个关键警告：**别把组队玩成角色扮演**。不是让模型「写得像个空头」，是让它「做空头研究仓位时会做的事」。前者污染 transcript 不改善结果。

三种野心共同的前提：模型得有电脑、能装软件、能访问数据（MCP 或其他方式）。纯对话窗口里玩不了这些。

## 为什么大多数人需要这份教程

心理学概念 **self-efficacy**（自我效能感）：相信自己能做到的人真的做得更多。而且这东西可被 hack——Locke 与 Latham 翻了 35 年目标设定研究：**给具体的高目标比说「尽力就好」表现更好**。Patrick Collison 的「Fast」清单记录的也是同一件事：大胆目标 + 紧 deadline 下的完成度。

三个经过验证的 hack：

1. **相信可能就能做到**：1939 年 George Dantzig 上统计课迟到，把黑板上的两个「作业」带回家解了——那是两道未解难题。（昨天 KV4-RL 里的 Hadamard 旋转、JSSA 的谱解，都是「把它当作业解了」的产物。）
2. **看别人做到之后自己也能**：Bannister 1954 年 5 月破四分钟一英里，纪录只独占了 46 天。今年 4 月伦敦马拉松 Sawe 跑进两小时，同场亚军也破了两小时。
3. **允许失败反而发挥更好**：《网球的内心游戏》的核心论点——特别用力反而打不出最好状态。工程师的版本是 Linux 的开场白：「just a hobby, won't be big and professional like gnu」。

Self-efficacy 不是新问题，但现在是新变量：**能力每几周跳一跳的世界里，最稀缺的是敢想「上周还不可能的这事现在可能了」的习惯。**

## 启发

- 四分法对「怎么用 agent/模型」这个问题是个好用的自检表：接到任务先问自己落在哪个象限。多数人 90% 的用法停在 Speed，Altitude 和 Depth 是工程师最容易上手的增量——前者问「goal beyond the goal」，后者问「顶尖专家会怎么干」。
- 这套方法论和这个知识库的日常其实是同构的：daily 速览是 Speed，精读笔记是 Depth，「insights 主题笔记」就是 Altitude（跳出单篇看方法地图），digest 的趋势节是 Range（跨子方向找模式）。四类野心在知识管理系统里各有一层对应物。
- 「外部裁判」那条对这个知识库尤其relevant：论文的数字不能只听论文自己说——复现要点节、疑问清单节，本质上都是在给「模型说的话」装外部验证。
- 名词换动词的技巧可以立刻用在写作上：把「我要写一篇 XX 的笔记」换成「我要让三个月后的自己不看原文也能重建这篇论文的决策链」，产出的形态马上不一样。

## 局限

- 作者立场决定了视角偏差：Anthropic EM 看到的「飞起的人」是幸存者偏差的极端样本，教程没有量化「四种野心」各自的失败率——拔高抽象和跨领域组队翻车的 case 一句没提。
- 技巧默认前提是模型有完整工具环境（电脑、装软件、数据访问），对纯对话场景的用户，Depth 和 Range 大半不可用。
- self-efficacy 论证是 motivational 的包装，不是因果论证：Dantzig 的故事更接近「错误前提下的高性能」，跟「相信自己就能做到」有微妙差别。

## 疑问清单

- 「定不讲理的目标 + 告诉模型这很合理」和「模型幻觉式迎合」的边界在哪？什么信号说明该退回合理目标，什么信号说明模型在硬凑？
- Altitude 拔到第三级（质疑流程本身）时，验证成本怎么控制？「并行跑一个季度」在个人工作流里对应什么轻量版？
- 四分法对 coding 之外的领域（研究、写作、管理）权重是否一样？Depth 在低反馈信号的领域（比如战略判断）怎么落地「外部裁判」？

## 新学到的术语

- **Self-efficacy（自我效能感）**（learning）：心理学概念，相信自己能做到的人真的 accomplish 更多；Locke & Latham 的目标设定研究证明具体高目标优于「尽力就好」
- **Goal beyond the goal**（learning）：Altitude 技巧核心自问——当前任务完成后你想发生什么，用来把任务改写成结果导向
- **名词换动词（Nouns to verbs）**（learning）：任务重述技巧，把「做一个 X」换成「完成 X 所服务的动词性目的」，让跨领域方法自动浮现
