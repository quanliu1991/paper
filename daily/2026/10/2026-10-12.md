## 🚀 推理 Infra（8 篇）

### 1. ⭐ SoloQ: Calibration-Free Quantization for Diffusion Language Models（upvotes: 30）
- **一句话**：扩散语言模型（dLLM）整段去噪要反复跑前向、块扩散还有 KV cache，部署很贵——这篇做出免校准数据的 4-bit 量化，峰值显存省 2.6 倍。
- **方法**：结构化旋转（K-RPBH）把权重/激活映到分布可预测的规范基上，不需要校准数据就能量化；块扩散模型的 KV cache 在 commit 时量化，不扰动正在去噪的块。支持 NVFP4 硬件原生格式。
- **结果**：LLaDA/Dream/Fast-dLLM v2 等 4-bit 精度保持，知识/推理基准反超校准式基线；峰值显存降 2.61x，端到端推理加速 2.24x。
- **链接**：[arXiv](https://arxiv.org/abs/2610.07121) · infra 相关性: 5/5 · 子方向: quantization-compression

### 2. ⭐ VisionWeave: Weaving Elastic Visual Representations as a Native Capability of MLLMs（upvotes: 52）
- **一句话**：视觉 token 该细的地方细、该粗的地方粗——把「弹性伸缩视觉表示」训成多模态模型的原生能力，平均省 43% token 只掉 1.1% 性能。
- **方法**：gated spatial pooler 在共享 MRoPE 坐标里同时构造粗/细两级表示，granularity router 按内容自适应分配；纯自蒸馏训练，Qwen3.5-4B 验证后扩到 27B（30K+ A100 时）。
- **结果**：平均省 43.0% token 保留 98.9% 性能（固定 50% 剪枝基线只保 88%）；SGLang 上吞吐 2.3x，TTFT 降 54.4%、TPOT 降 60.6%。
- **链接**：[arXiv](https://arxiv.org/abs/2610.07987) · infra 相关性: 4/5 · 子方向: long-context-vlm

### 3. ⭐ QuantMLA: Function-Aligned Dual-Path Quantization for Low-Bit MLA KV Caching（upvotes: 1）
- **一句话**：MLA（DeepSeek 式潜在注意力）的 KV cache 有内容/位置两条路，低比特量化一直难做——这篇给出首个双路联合 INT4 方案，128K 上下文压缩 3.59 倍。
- **方法**：系统建模双路量化误差（RoPE 路误差会被放大），推出保精度的路径专属变换空间（可离线融进权重），content 路用注意力输出重构、RoPE 路用 QK 重构做函数对齐目标；配套原生低比特 MLA attention kernel。
- **结果**：4 个 MLA 模型族 content+RoPE 双 INT4 精度几乎不掉；128K 物理 cache 布局压缩 3.59x，cache 压力负载整卡输出吞吐 5.17x。
- **链接**：[arXiv](https://arxiv.org/abs/2609.36760) · infra 相关性: 5/5 · 子方向: kv-cache

### 4. ⭐ Contextual Correction of Parallel Drafts for Speculative Decoding（upvotes: 18）
- **一句话**：并行 drafter（DFlash 一类）一次画出多个 token，但块内 token 互相看不见彼此——DCOCO 用轻量纠正器把「块内依赖」找回来，并发 serving 下还快 6–23%。
- **方法**：不提交各位置 top-1，保留多候选 token，并行评估相邻位置的上下文兼容性再选；开销小，保持并行起草。
- **结果**：4 种 verifier × 10 基准全部最高吞吐，greedy/随机解码最高 6.6x；4–32 并发下比最强对手快 6–23%，串行纠正器在高并发反而不如不纠正。
- **链接**：[arXiv](https://arxiv.org/abs/2610.12570) · infra 相关性: 5/5 · 子方向: speculative-decoding

### 5. ⭐ PreSTO: Predictive Subtree Prefetching for Fast LLM Power Sampling（upvotes: 9）
- **一句话**：test-time 采样里 PowerMH 的接受/拒绝要一步一步来，慢——把「未来的接受拒绝决策」看成一棵树，一次模型调用预取整棵子树，数学上严格等价原采样器。
- **方法**：每轮批量生成一棵预取子树的 proposal，沿真实路径走原 MH 接受规则；观察到 MH 只走到树的稀疏近单叉区域，设计预测式遍历选子树最大化完成的转移数。
- **结果**：7 数据集 × 5 模型，PowerMH/EntropyCut/MultiTryMH 中位加速 1.71/1.91/2.33x；模型调用少 3.9 倍、每次只长 2.1 倍。
- **链接**：[arXiv](https://arxiv.org/abs/2610.13171) · infra 相关性: 4/5 · 子方向: inference-other

### 6. ⭐ MixTok: Adaptive Visual Tokenization with Global 1D Tokens and Sparse 2D Refinement（upvotes: 11）
- **一句话**：视觉 tokenizer 在「1D 紧凑但不保细节」和「2D 网格保细节但均匀铺」之间折衷——全局用 1D、只在高分位置稀疏补 2D，128 token 就够重建。
- **方法**：内容自适应 router 按细化优先级排序候选位置、按预算定 2D token 数；高分位置的 2D 特征替换 1D 恢复的空间特征，共享 decoder 重建。
- **结果**：ImageNet 256 平均 ~128 token：rFID 1.195、gFID 1.95。
- **链接**：[arXiv](https://arxiv.org/abs/2610.13181) · infra 相关性: 4/5 · 子方向: long-context-vlm

### 7. ⭐ Stateless Language Agents: Scaling Long-Horizon Automated Research（upvotes: 9）
- **一句话**：长时程自动化研究里 agent 反复回放历史、互相重复劳动——把「研究状态」从对话里抽出来交给 harness 管，agent 每次调用都是无状态的新鲜上下文。
- **方法**：stateful search + stateless agents：harness 持有候选解与实验结果，按角色重建上下文；Advisor 读全局证据派实验，并行 Worker 执行。
- **结果**：十亿 token 预算下每个任务结果最好，达到最强 kernel 基线的最终性能只用 17% 的 token；Advisor 只吃 0.6% token。
- **链接**：[arXiv](https://arxiv.org/abs/2610.07625) · infra 相关性: 4/5 · 子方向: inference-other

### 8. ⭐ MetaKernelBench: Measuring GPU Kernel Knowledge Transfer Beyond Code（upvotes: 11）
- **一句话**：GPU kernel 优化 agent 学到的「经验」到底能不能跨 DSL 复用——74 对只差 DSL 的孪生题，测蒸馏出的技能迁移是加分还是帮倒忙。
- **方法**：agent 先独立解一个 DSL 变体、把所学蒸馏成自然语言技能，同一模型带技能解另一个 DSL；与无技能对照比正确率与端到端耗时。
- **结果**：6 模型双向配对提升 -19% 到 +29%；每个模型/方向都有 16–45% 的题出现回退。
- **链接**：[arXiv](https://arxiv.org/abs/2610.05014) · infra 相关性: 4/5 · 子方向: inference-other

## 👓 今日推荐
- **DCOCO（Contextual Correction of Parallel Drafts）** — 你精读过 DLoop 并追问过投机解码的失败粒度与并发行为，DCOCO 正好是并行 drafter 的块内依赖修复，与 DLoop 的「连续起草」互补。[arXiv](https://arxiv.org/abs/2610.12570)

## 📖 今日新词
- **dLLM（扩散语言模型）**（learning）：用双向扩散过程并行生成 token 的语言模型（LLaDA/Dream），整段去噪反复前向、块扩散带 KV cache，部署成本高
- **MLA（Multi-Head Latent Attention）**（learning）：DeepSeek 式潜在注意力，KV cache 压缩成低秩潜在向量，但内容/位置双路给量化带来新难题
- **PowerMH**（unknown）：test-time 从锐化分布采样的 Metropolis-Hastings 采样器，串行接受/拒绝是瓶颈
