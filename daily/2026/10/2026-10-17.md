## 🚀 推理 Infra（25 篇）

### 1. ⭐ MOSAIC: Multi-Objective Search for Allocating Inference Cache Across LLM Decoder Layers（upvotes: 0）
- **一句话**：KV 驱逐别再给每层发一样的预算——用多目标搜索给每层学出自己的 token 预算
- **方法**：在 SnapKV/H2O/AdaKV/L2Norm 等任何驱逐方法之上，用神经架构搜索学 per-layer KV 预算；一次搜索画出「平均预算 vs 任务分」权衡曲线，最优分配可迁移到任意目标预算，无需重搜
- **结果**：四个驱逐方法 × 多任务上统一提升（细节见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.25431) · infra 相关性: 5/5 · 子方向: kv-cache

### 2. ⭐ When Does Better Acceptance Pay? A Controlled Study of Speculative Decoding（upvotes: 0）
- **一句话**：把各家 drafter 放到同一训练/推理条件下重新测——发表对比里的大差距会大幅缩水
- **方法**：建立横跨训练、推理、评测的对照协议：重测已发布 checkpoint + 在共享 target 生成数据上重训六种 drafter 配方，10 个基准 × 2 个 target
- **结果**：对齐条件后差距显著收窄；「多接受一个 token 值不值」取决于接受长度与执行延迟的权衡
- **链接**：[arXiv](https://arxiv.org/abs/2610.24993) · infra 相关性: 5/5 · 子方向: speculative-decoding

### 3. ⭐ Acceptance Is Not Speed: Length Inflation in Training-Free Lossy Speculative Decoding（upvotes: 0）
- **一句话**：宽松验证的投机解码会「注水」——接受率上去了，但回答变长了，提速大部分被吃掉
- **方法**：识别 length inflation 现象：relaxed 验证接受的 token 改变输出分布，主要是拉长 reasoning 轨迹；系统评测 training-free lossy 方法
- **结果**：表面 accepted tokens/round 的增益大部分被完成长度增长抵消
- **链接**：[arXiv](https://arxiv.org/abs/2610.23818) · infra 相关性: 5/5 · 子方向: speculative-decoding

### 4. ⭐ Certified Sparse Attention via Perturbed Retrieval（upvotes: 0）
- **一句话**：稀疏注意力终于有了「误差保证」——给每个 key 的分数加一点随机扰动，检索变成按注意力权重采样，还能给出置信界
- **方法**：独立 Exp(1) 扰动把 threshold retrieval 变成按注意力概率采样；几何网格降阈值得嵌套样本 + Horvitz-Thompson 估计，全层级联置信界同时成立，每个 head 在误差界内即停
- **结果**：真实 KV cache 上误差重尾问题得到控制，长上下文解码加速（详细数字见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.24991) · infra 相关性: 5/5 · 子方向: kv-cache

### 5. ⭐ TideKV: Delayed KV Eviction via Layer-Wise Chunked Prefill for Memory-Efficient Long-Context LLM Inference（upvotes: 0）
- **一句话**：长 prompt 的显存峰值不只在 decode——prefill 建缓存时就得留全量 KV；TideKV 按层延迟驱逐，压掉这个峰值
- **方法**：layer-major 延迟驱逐：逐层 chunked prefill，等每层看完整 prompt 后再驱逐，兼顾在线驱逐的省显存与全量 prefill 的质量
- **结果**：显存高效的 on-GPU cache 构建（细节见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.24499) · infra 相关性: 5/5 · 子方向: kv-cache

### 6. ⭐ DLite: History-free Speculative Decoding for Agentic AI（upvotes: 0）
- **上下文**: agentic 负载长且不断演化的上下文让现有 drafter 接受长度掉最多 80%，维护历史 KV cache 又有系统开销——这题正好和知识库里 GraphTok/CarryOn 一条线
- **一句话**：给 agent 场景的投机解码——抛弃历史上下文的 draft 策略，省掉 drafter 的 KV 维护开销

## 📖 今日新词

- **Length inflation（宽松验证注水）**（learning）：relaxed 验证改变输出分布、主要拉长 reasoning 轨迹，表面接受率收益被完成长度增长吃掉
- **Layer-major delayed eviction（层主序延迟驱逐）**（learning）：逐层 chunked prefill、每层看完整 prompt 后再驱逐，压 prefill 显存峰值而不牺牲驱逐质量
- **Trajectory-shape trigger（轨迹形状触发）**（learning）：sparse collaborative decoding 中决定何时调用大模型的信号——局部熵/margin 无区分度（AUC≈0.5），聚合轨迹形状特征才有
- **Proposal-refined index sharing（提案-细化索引共享）**（learning）：稀疏注意力跨层共享索引的两段式——锚层出 proposal、非锚层低成本细化
- **BFP bit-sharing（块浮点位共享）**（learning）：block floating point 块内共享指数位，自投机解码中同时管 draft 构造与混合精度的框架
