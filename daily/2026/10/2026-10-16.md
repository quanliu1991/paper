### 1. ⭐ When the KV Cache Is Slower Than the GPU: Scaling Remote KV Tiers for Context-Parallel Prefill（upvotes: 0）
- **一句话**：生产事故复盘——给 GLM-5.3 加远程 KV 层后 16k prompt 的 p99 从 3.96s 涨到 17.3s，因为命中一次 0.88s、重算只要 0.31s
- **方法**：成本模型 T_load = T₀ + ns/B 两个致命参数：盈亏平衡带宽 B\*=sR=2.53 GB/s（单 Valkey 只给 1.71），固定成本 T₀≈0.33s 意味着短于 17k token 的命中任何带宽下都不划算；修复=MLA KV 按 chunk 分片到 PCP rank + 每 rank 专属 Valkey 实例（带宽 ×6.3）+ 异步加载 + 修三个客户端 bug
- **结果**：hit-heavy p99 从 83.32s 降到 0.67s（124×），prefill 吞吐 +34%，全部改动提上游 LMCache/FlashInfer
- **链接**：[arXiv](https://arxiv.org/abs/2610.21500) · infra 相关性: 5/5 · 子方向: serving-system
- 📝 [精读笔记](../../notes/papers/2026-10-16-remote-kv-tiers.md)

### 2. ⭐ Close Enough is Nowhere Near: Fidelity-Consumability Decoupling in KV Caches（upvotes: 0）
- **一句话**：把 A 模型的 KV cache 零训练塞给 B 模型替换它自己的——6000 个真 key 里最近的那个都嫌远，必死；但当「额外上下文」挂上去就能超过 B 自己的基线
- **方法**：三组测量钉死 tolerable set 的窄度（cosine 0.9999 已失效、28 层坏 1 层=全坏、流形上选择也无效）；机制是 softmax 竞争性——key 互相比赛，微小位移翻转胜负；cosine/MSE 把好坏方法排反
- **结果**：八种替换方法全部贴 floor；augmentation + query 侧 LoRA 达 0.695 追平 native 参考 0.665；多 sender 池 8 个仍可用
- **链接**：[arXiv](https://arxiv.org/abs/2610.22016) · infra 相关性: 5/5 · 子方向: kv-cache
- 📝 [精读笔记](../../notes/papers/2026-10-16-kv-fidelity-consumability.md)

### 3. ⭐ Speculative Forcing for Efficient Autoregressive Video Generation（upvotes: 67）
- **一句话**：少步自回归视频生成器给每个 token 都跑完整去噪太浪费——多数 token 早期就接近终值，让它们提前「冻结」出场
- **方法**：把中间干净估计当草稿，逐 token 预测何时可安全提前接受；接受后冻结为最终输出、其 KV 保留当上下文；验证器两种（training-free 相似度+稳定性 / 学习式读冻结生成器中间特征）
- **结果**：视频 AR 生成显著提速（scheduled forcing 框架的投机解码化），质量保持
- **链接**：[arXiv](https://arxiv.org/abs/2610.22347) · infra 相关性: 4/5 · 子方向: speculative-decoding

### 4. LoopAhead: Speculating Ahead for Faster Decoding in Looped Language Models（upvotes: 0）

- **方法**：轻量 lookahead drafter（LAD）用 early-loop 状态多 token 起草，deep-loop 反馈纠正草稿方向
- **结果**：比现有 pipelined 自投机解码更长 lookahead、不浪费算力验证错误分支

## 📖 今日新词

- **Break-even bandwidth（B\*=sR）**（learning）：缓存命中开始划算所需的传输带宽 = 每 token KV 字节 × GPU prefill 速率；GPU 越快门槛越高
- **Prefill Context Parallelism（PCP）**（learning）：prompt 沿序列切到多 GPU，AllGather 交换 KV 锁步推进；一个 rank 停顿拖住全体
- **Tolerable set**（learning）：冻结 reader 能正确消费的 cache 邻域；各向异性，注意力分辨的方向上极薄，范数指标测不出
- **Fidelity-consumability 解耦**（learning）：几何相似度与能否实际使用是独立谓词；cosine/MSE 可优化到最优而可消费性缺席
- **Competitive attention**（learning）：softmax 让 key 互相比赛而非对标阈值，微小位移可翻转胜负——KV 跨模型替换失败的机制根源
