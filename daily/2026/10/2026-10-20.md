## 🚀 推理 Infra（33 篇，净新增约 14）

### 1. ⭐ DScout: Factorization-Guided Training and Inference for Diffusion-Drafted Speculative Decoding（upvotes: 5）
- **一句话**：扩散 drafter 提案容量越大 ≠ 吞吐越高——验证只接受连续前缀，早拒让后面白对；两个互补因子分解指导训练与推理
- **方法**：DScout 用训练与推理两侧的因子分解缓解「早拒作废后续正确预测」与「MAT 涨但每轮延迟也涨」两个失效模式
- **结果**：扩散 drafter 吞吐提升（细节见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.23935) · infra 相关性: 5/5 · 子方向: speculative-decoding

### 2. ⭐ Remembering Has a Price: Learning Memory Worth under Resource Constraints（upvotes: 5）
- **一句话**：资源紧张时「记什么」本身变成高价值决策——多数复杂终身记忆方法在紧预算下还不如简单检索甚至不记忆
- **方法**：生成/交互/记忆三重预算约束下的 memory worth 学习
- **结果**：紧约束场景记忆策略重新排序（细节见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.26453) · infra 相关性: 4/5 · 子方向: long-context-vlm

### 3. ⭐ MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents（upvotes: 21）
- **一句话**：agent 记忆系统大多「查询无关」地预处理一切——按需策展：运行时灵活编排记忆操作，控制性能/成本/延迟
- **方法**：灵活的记忆策展编排层（query-aware 处理时机与粒度）
- **结果**：记忆成本与后续查询命中同时改善（细节见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.06830) · infra 相关性: 4/5 · 子方向: long-context-vlm

### 4. ⭐ A Conditional No-Hair Theorem for Transformers: How Language Models Forget Their Prompt（upvotes: 4）
- **一句话**：模型生成 t 个 token 后还记得多少 prompt——hidden state 距离按幂律 t^(-α) 衰减，训练过的模型忘得快（α≈0.55-0.7）
- **方法**：同 continuation 不同 prompt 的对照实验 + 理论证明偏移界 O(P(log t)^(L-1))
- **结果**：长上下文复用的有效窗口有了理论刻画（对 KV cache 生命周期管理有直接含义）
- **链接**：[arXiv](https://arxiv.org/abs/2610.24133) · infra 相关性: 3/5 · 子方向: kv-cache

### 5. ⭐ Competing Learning in Hybrid Architectures（upvotes: 4）
- **一句话**：混合架构里线性递归层和 softmax attention 会「抢着学」同一个函数——一层学会了就抑制其他层的学习信号
- **方法**：Competing Learning 现象的识别与机制分析
- **结果**：混合架构训练动力学的一手洞察（对 RadixFlow 线的 hybrid 模型 serving 是背景知识）
- **链接**：[arXiv](https://arxiv.org/abs/2610.26830) · infra 相关性: 3/5 · 子方向: models

### 6. ⭐ ECHO: Efficient Causal Self-Recursion Beyond Auxiliary Multi-Token Prediction（upvotes: 3）
- **一句话**：MTP 每 added horizon 一个模块一次前向太贵——backbone 自己的末层预测所有 horizon，训练深度按衰减概率采样
- **方法**：Dynamic Depth Sampling（DDS）+ 自递归；未来预测成为自回归主干的一部分
- **结果**：多 token 预测训练成本大降（细节见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.24766) · infra 相关性: 4/5 · 子方向: speculative-decoding

### 7. ⭐ KronLSTM: Kronecker Delta Rule for Long Context Linear Attention（upvotes: 21）
- **一句话**：Kronecker delta 更新规则——矩阵记忆的单方向最小侵入修订，改目标关联的同时不干扰已存信息
- **方法**：xLSTM 家族扩展；记忆动力学可描述为马尔可夫链
- **结果**：长上下文线性注意力的记忆干扰降低（细节见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.26834) · infra 相关性: 4/5 · 子方向: long-context-vlm

### 8. ⭐ HSPR: Recovering Software-Agent Benchmark Scores via Hierarchical Posterior Inference（upvotes: 3）
- **一句话**：跑全基准太贵、小子集分数不准——分层后验恢复：源 agent 历史响应因子 + 组成功率不确定性 + 后验引导选题
- **方法**：Hierarchical Score Posterior Recovery
- **结果**：低成本高精度恢复 agent 分数（细节见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.24611) · infra 相关性: 3/5 · 子方向: inference-other

## 📖 今日新词

- **MAT（Mean Accepted Tokens）**（learning）：投机解码每轮平均被接受 token 数；DScout 指出它涨吞吐未必涨——早拒作废后续 + 每轮延迟上升两个失效模式
- **Memory worth（记忆价值）**（learning）：资源约束下「这段经历值不值得记」本身成为学习问题；紧预算下多数复杂记忆方法不如简单检索
- **Competing learning（竞争学习,混合架构）**（learning）：线性递归层与 softmax attention 抢学同一函数，一层学会抑制他层学习信号
- **On-demand memory curation（按需记忆策展）**（learning）：agent 记忆不做查询无关的全量预处理，运行时按查询编排策展操作
