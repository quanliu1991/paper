## 🚀 推理 Infra（28 篇，新增 17）

### 1. ⭐ ALLOT: Sparsity Should Be ALLOTted by Output（upvotes: 11）
- **一句话**：视频生成的「哪些层哪些步该多留注意力块」别拍脑袋——离线测一次「最终视频损伤」的敏感度表，求解器按延迟预算分配，比人工规则好 7 dB
- **方法**：cell probing（单层稀疏测误差）+ trajectory calibration（窗口化全生成捕捉早步误差被放大几百倍）+ 实测延迟表，Lagrangian 二分求解
- **结果**：四模型六策略全胜 1.53-7.31 dB；等墙钟时间 PSNR 25.37 vs 18.14；每模型 6-23 GPU 时一次性标定
- **链接**：[arXiv](https://arxiv.org/abs/2610.29441) · infra 相关性: 5/5 · 子方向: long-context-vlm
- **精读**：[笔记](../../notes/papers/2026-10-22-allot.md)

### 2. ⭐ Cache Engineering for Agents（upvotes: 45，10-21 已收录，今日热榜）
- **一句话**：agent 的历史管理别在文本层动刀——直接 drop 掉不要的 KV cache，保留的原地复用，零 re-prefill
- **方法**：append/drop/repos 三个 cache 原语 + AKV serving 引擎（扩展 radix tree + segment-batch attention）
- **结果**：成本 −27.7%、分数 +1.7 点，P95 延迟 1.5×，输出吞吐 1.2×（vs 阈值摘要）
- **链接**：[arXiv](https://arxiv.org/abs/2610.28577) · infra 相关性: 5/5 · 子方向: kv-cache
- **精读**：[10-21 笔记](../../notes/papers/2026-10-21-cache-engineering-akv.md)

### 3. ⭐ Looking Ahead: FCP — Modeling Future Evolution in Autoregressive Video Generation（upvotes: 38）
- **一句话**：自回归视频模型在 teacher forcing 下学会作弊——靠局部画面连续性蒙混当前块去噪，根本没学「场景会怎么演化」；逼它预测看不见的远处块，物理合理性大增
- **方法**：Future Chunk Prediction 辅助目标：预测时间上隔断的 chunk（不给中间视觉上下文），监督直接来自训练视频，推理零改动
- **结果**：物理合理性显著优于标准 teacher-forced 训练，且总训练算力更低；可视化显示表征空间更有结构
- **链接**：[arXiv](https://arxiv.org/abs/2610.29989) · infra 相关性: 4/5 · 子方向: long-context-vlm

### 4. ⭐ MCCL: Memory-Centric Continual Learning for AI Agents（upvotes: 15）
- **一句话**：agent 的记忆系统不该按「能不能背出存过什么」考评，该按「能不能让下一次行动更好」考评——被动检索缓存 → 主动持续学习
- **方法**：substrates/assets/policies 三轴分类 + 内环更新记忆状态、外环用任务反馈精炼管理策略的双循环；评测协议测干扰下保持/变化适应/任务迁移
- **结果**：概念框架 + 评测协议 + 记忆 scaling 模型三件套，把 agent memory 从 lookup 表推向持续学习
- **链接**：[arXiv](https://arxiv.org/abs/2610.29357) · infra 相关性: 4/5 · 子方向: serving-system

### 5. ⭐ DeLoop: Repeated Actions as Self-Supervision for Long-Horizon Agents（upvotes: 5）
- **一句话**：长任务 agent 老干蠢事——重复发同一个工具调用拿回一样的结果；用自己的 rollout 当标签训练「别重复」
- **方法**：识别 rollout 中的重复循环，构造对比样本自监督训练；历史被压缩后循环暴增，正好用压缩前 rollout 做监督源
- **结果**：Qwen/Llama/Gemini agent 天然都出现循环；压缩历史后循环更频繁——训练后显著减少
- **链接**：[arXiv](https://arxiv.org/abs/2610.19376) · infra 相关性: 4/5 · 子方向: serving-system

## 📖 今日新词
- **层-步敏感度（Layer-step Sensitivity）**：稀疏化某一层某一步的注意力对最终输出的伤害程度——跨层差可达 154 倍，且哪个层-步最敏感每个模型不一样，但排序跨输入稳定（learning）
- **轨迹校准（Trajectory Calibration）**：用窗口化完整生成测「误差跨步放大」——早步的小误差会被后续去噪放大几百倍，单步误差完全看不出这一点（learning）
- **连续性捷径（Continuity Shortcut）**：自回归视频模型在 teacher forcing 下靠相邻帧的局部连续性「蒙」当前块去噪，逃避对场景真实演化的建模（learning）
