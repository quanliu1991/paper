### 1. ⭐ The KV-Surgeon: Compensation-Aware Offline KV-Cache Compaction（upvotes: 0）
- **一句话**：离线压缩 KV cache 时删谁都不该「单独打分」——softmax 重归一化把所有删除决策耦合在一起，删一个会改变剩下每一个的注意力权重
- **方法**：compensation-aware 删除：删除决策考虑对剩余条目的非线性补偿，而非逐条独立评分（与 10-16 Competitive Attention 结论互证：softmax 是比赛，牵一发动全身）
- **结果**：固定上下文反复查询场景的成本降低（细节见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.25933) · infra 相关性: 5/5 · 子方向: kv-cache

### 2. ⭐ Tandem: Serving Hybrid Linear-Attention GUI Agents on Mobile NPUs（upvotes: 0）
- **一句话**：手机 GUI agent 每步动作都在攒延迟——混合线性注意力模型省显存，但 recurrent state 复用需要检查点，而 agent 请求「留指令、改历史」的改写模式让聊天式前缀缓存失效
- **方法**：为 agent 负载设计的 checkpoint/rollback 策略，NPU 上的 hybrid 线性注意力 serving
- **结果**：移动端 GUI agent 延迟降低（细节见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.26660) · infra 相关性: 5/5 · 子方向: serving-system

### 3. ⭐ ReAnchor: Reusing Rejected Verifier States for Diffusion Drafting（upvotes: 0）
- **一句话**：验证器在第一个拒绝点之后的 hidden states 通常被扔掉——把它们捡起来当新锚点，训练免费地并行起草多个 draft 块
- **方法**：training-free：用被丢弃的 verifier states 在移位位置重新锚定预训练 drafter，生成并行 draft 块（与 10-15 JetSpec++ 的 foresight 思路同族：榨取验证阶段「顺带」算出的东西）
- **结果**：块扩散 drafter 草稿延伸更远（细节见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.26531) · infra 相关性: 5/5 · 子方向: speculative-decoding

### 4. ⭐ MX-Like Tensor Core for LLM Inference with NPU Integration via Hardware-Software Co-Design Exploration（upvotes: 0）
- **一句话**：MX/NVFP4 块缩放量化格式满天飞，但 shared scale × 权重 × 激活的格式组合空间没人系统扫过——软硬件协同设计探索真正的 Pareto 最优
- **方法**：HW-SW co-design 探索 MX-like 设计空间，NPU 集成的 tensor core 微架构评估
- **结果**：边缘 NPU LLM 部署的精度-硅面积权衡曲线（细节见论文）
- **链接**：[arXiv](https://arxiv.org/abs/2610.26083) · infra 相关性: 5/5 · 子方向: quantization-compression

### 5. ⭐ CEMA-Router: Infrastructure-Aware Batch Routing for LLM Inference in Cloud-Edge Systems（upvotes: 0）

- **方法**：batch 级路由决策（非逐 query），联合响应质量、成本、能耗、批完成时间

## 📖 今日新词

- **Compensation-aware deletion（补偿感知删除）**（learning）：KV 压缩的删除决策被 softmax 重归一化非线性耦合，单独打分次优——删除需考虑对剩余条目的补偿
- **Memory-native（记忆原生）**（learning）：把记忆作为模型计算的内生部分（token 级状态更新 + 分层存储），而非外挂检索
