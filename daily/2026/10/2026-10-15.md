### 1. ⭐ KV4-RL: Unlocking Faster Asynchronous Rollouts for RLVR with INT4 KV Cache Quantization（upvotes: 26）
- **一句话**：异步 RL 训练里生成提速的新答案——把 KV cache 草稿纸压成 INT4，只给开头和最近位置上 INT8 保险
- **方法**：先证明异步 rollout 结构性地把 KV 负载压进更少 decode step（KV concentration，浓度因子随回答长度方差增大），此时量化 KV 比量化权重加速大得多；裸 INT4 会让策略学坏，用有界 INT8 边车保护 attention sink（s=16）+ 最近窗口（w=128），TIS 兜底
- **结果**：Qwen3-8B GRPO rollout 累计提速 1.80×（后期 1.97×），六基准均值与 BF16 训练差 <0.5 分；裸 KV4 掉 4.6 分
- **链接**：[arXiv](https://arxiv.org/abs/2610.14448) · infra 相关性: 5/5 · 子方向: kv-cache

### 2. ⭐ JetSpec++: Foresight Parallel Drafting with Self Refinements（upvotes: 0）
- **一句话**：大模型验证第 t 块时，小模型在另一张卡上猜验证结果、提前写好第 t+1 块草稿，起草时间从 3.8ms 藏到 0.66ms
- **方法**：adapter 预测目标 hidden state + decoder 算结局分布 P(接受数k, bonus a)，押注 B=16 条「世界线」预起草；验证窗口内跑 Jacobi 自我精修 + anchor replacement 修 prefix-blind
- **结果**：GB200 单请求 1361 tok/s，AR 7.45×、DSpark 1.54×；τ=8.94 全面领先，输出分布严格不变；代码开源
- **链接**：[arXiv](https://arxiv.org/abs/2610.19792) · infra 相关性: 5/5 · 子方向: speculative-decoding

### 3. LatentLoop: Scaling Looped MoE Models with Asymmetric Compute Allocation（upvotes: 56）
- **一句话**：循环两次的 MoE 发现第一次循环「干活轻」，压缩首访序列、省下算力加宽隐层，白赚性能
- **方法**：loop 访问角色不对称（首访 residual 系数小）；首访压缩序列、次访全分辨率，MoE 权重共享 + attention 参数分离
- **结果**：1.3B-7B 15 种配置（最大 10^21 FLOPs）验证 NLL 一致更低，等 NLL 下更省算力

### 4. ReaDy: Recurrent States as Dynamic Context for Speculative Drafting in Hybrid Linear Attention LLMs（upvotes: 0）

### 5. FOLD: Position-Free Far Memory with Local Order for Long-Context Speculative Decoding（upvotes: 0）
- **一句话**：长上下文 drafter 免训练加速——近处保精确位置，远处全部当作共享位置的「远记忆」并锐化注意力
- **方法**：训练无关；远记忆条目共享同一位置编码，注意力 dilution 用锐化 + 总权重控制对抗；drafter 轻量所以全历史注意力付得起

### 7. PN-Mix: Pair-Norm Guided Mixed-Precision Key Cache Quantization（upvotes: 0）
- **一句话**：KV 量化到 2-bit 的关键在 RoPE 通道对——query-key pair-norm 大的通道对量化误差放大 logit 扰动，prefill 时一次性识别、解码全程复用

## 📖 今日新词

- **KV concentration**（learning）：异步调度把同样的 KV 处理压进更少 decode step，单步 KV 负载结构性增大；浓度因子 E[max]/E[L]≥1，回答长度方差越大越严重
- **Attention sink**（learning）：模型对序列开头少数 token 的异常高注意力，量化/压缩 KV 时开头位置需重点保护
- **Calibration-free 量化**（learning）：不靠离线校准集、对每个新向量在线算量化参数，策略/分布漂移时天然免疫
- **Foresight drafting**（learning）：验证未结束时预测目标 hidden state 和验证结局分布，提前起草下一块，使起草脱离关键路径
- **Jacobi 迭代起草**（learning）：把草稿块当输入反复前向，每轮用前面位置的结果修正后面位置，逼近逐 token 因果分解
- **Prefix-blind**（learning）：并行预测各位置互看不到对方选的 token，可能拼出上下文不允许的组合（如「of problem」）
