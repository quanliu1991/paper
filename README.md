# AI 论文知识库

每日自动更新的 AI 前沿论文知识库，重点沉淀**推理（Reasoning）**方向。由 Cursor Agent 每天 21:00 定时抓取分析（详见 [AGENTS.md](AGENTS.md)）。

## 数据源

- [HuggingFace Daily Papers](https://huggingface.co/papers)（社区策选，带 upvotes 热度）
- arXiv 关键词订阅（`config/keywords.yaml` 可调）
